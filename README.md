# AI Data Analyst 📊

An AI-powered data analysis web application that allows users to upload CSV or Excel datasets and analyze them using natural language.

Instead of writing Python or SQL queries manually, users can simply ask questions about their data and get AI-powered answers, insights, and visualizations.

## 🚀 Features

- 📁 Upload CSV and Excel datasets
- 📊 Dataset overview and statistics
- 🔎 Missing value detection
- 💬 Ask questions in natural language
- 🤖 AI-powered data analysis
- 💡 Automatic dataset insights
- 📈 AI-generated charts
- 📊 Bar, Line, Pie, Scatter and Histogram charts
- 🎤 Voice-based questions
- 🔊 AI-generated voice responses
- 💭 Follow-up questions with conversation history
- 🐍 AI-generated Python analysis code
- ☁️ Streamlit Cloud deployment

## ⚙️ How It Works

1. Upload a CSV or Excel dataset.
2. The application analyzes the structure of the dataset.
3. Ask a question in natural language.
4. AI generates Python analysis for the question.
5. The generated analysis is executed on the dataset.
6. The result is explained in simple language.
7. Supporting data and visualizations are displayed.
8. Users can continue asking follow-up questions.
